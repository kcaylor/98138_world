The LEGO World Map, re-imagined with real data

The World Map kit (31203) is a 128 × 80 grid of 10,240 round pieces: white plates for land, tiles in nine colors for the ocean. This site keeps that grid and its coastline as a fixed template and fills it from global datasets. Pick a map, choose how to hang the three frames, and download everything you need to build it.

How it works

  1. Template. The kit's grid, coastline and two part types never change.
  2. Layers. Each map is a land layer and an ocean layer, each either data-driven (a dataset classified onto an ordered color scale) or a shaded background.
  3. Build files. Every map comes with a parts list with BrickLink and Rebrickable IDs, wanted lists, and printable section-by-section build sheets.
