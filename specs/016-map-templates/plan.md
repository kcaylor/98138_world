# Implementation Plan: Map templates

**Branch**: `016-map-templates` | **Date**: 2026-11-23 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/016-map-templates/spec.md`

## Summary

Add templates to the CLI library: the kit (`kit-31203`, built in code from its existing files,
default and unchanged) and one new confirmed template, `winkel-tripel` (Winkel tripel, φ1
50.4598°, λ0 11.1° E, on the kit's 8 × 5 modules and frame). A maintainer tool built on the
projection study generates the Winkel layout from pinned ETOPO 2022 with pyproj, writes a review
sheet outside the repository, records corrections and the owner's confirmation, and proves the
committed file with `--check`. The package data file carries everything the run time needs (stud
classes, stud locations, the fit), and a six-line numpy forward formula bins data into studs, so
`map build` and the web image need no new dependency. Maps on a template sample data at each
stud's location, keep the margin out of every layer, and fill it with 1×1 square tiles (part
3070b) in a margin color with an optional outline ring; parts lists, exports, prices, sheets,
validation, `map cells` and (P2) the web site handle the third part. Kit outputs stay byte for
byte the same, proven by golden digests taken before any code change. Margin labels are not part
of this feature: they moved to feature 017 (map stickers) on 2026-11-23.

## Technical Context

**Language/Version**: Python 3.11 (CLI, tools, web); browser JavaScript ES2017 (`palette.js`)

**Primary Dependencies**: existing only at run time (numpy, scipy, Pillow, Click, reportlab,
h5py; FastAPI, Jinja2). Maintainer group only: **pyproj `>=3.7,<3.8`** (MIT; 3.8 needs Python
3.12; research R4)

**Storage**: package JSON (`data/templates/winkel-tripel.json` about 170 kB,
`winkel-tripel-ice.json`; 3070b rows in `part_colors.json` and
`part_numbers.json`); per-user dataset cache; prebuilt static site

**Testing**: pytest (cli unit/integration/contract, web offline); kit golden digests; Node for the
chooser's pure functions when installed; the one pyproj end-to-end tool test is skipped without
pyproj

**Target Platform**: CLI on macOS/Linux; Fly.io service; current browsers

**Project Type**: CLI + library + maintainer tools + web service

**Performance Goals**: a Winkel build within 2× the kit build of the same recipe; template load
< 100 ms (cached); web prebuild +20 % (24 → 29 variants)

**Constraints**: kit outputs byte-for-byte unchanged (SC-001); tests offline (SC-007); the service
never imports `lego_image_processor`; no new runtime or web dependency; review sheets and
candidates stay outside the repository; no personal name in committed files

**Scale/Scope**: 1 new template, 1 new part, 5 web variants; about 40 files touched

## Spec notes and escalations

1. **Decided (agent, close call): fit (R2).** The spec's counts (2,554 / 5,706 / 1,980, ring 286, corners 15 × 13,
   leftovers 510 and 2,360) come from the study's grid-sampled extent. The exact published extent
   gives 2,553 / 5,691 / 1,996, ring 288, corners 14 × 14, leftovers 511 and 2,375, and a
   symmetric mask. Decision: the exact extent; acceptance uses the confirmed counts (US1-1,
   SC-002 already allow it).
2. **Decided (agent, close call): previews (R13).** FR-012 asks for round studs; every preview today is one square
   per stud, and changing kit previews breaks SC-001. Decision: rounds and squares on non-kit
   previews only; kit previews unchanged. Superseded 2026-11-23: main 6038d9c draws round studs
   on black for every map preview, so 016 uses main's drawing for land and ocean and adds square
   margin and ring studs; the kit golden was re-based on 6038d9c (research R13).
3. **Spec note: FR-013.** "Reports name the template" is read as non-kit reports only (absent =
   kit, as for layouts), so kit reports stay byte-identical (SC-001).
4. **Owner steps** (not escalations): reviewing and confirming the Winkel template (phase 3);
   refreshing the price snapshot with BrickLink credentials (Winkel estimates stay incomplete
   until then); providing another pinned source if the Internet Archive has no copy of the
   BrickLink or Rebrickable 3070b page.
