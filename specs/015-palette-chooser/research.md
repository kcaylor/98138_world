## R2. JavaScript within the constitution and 008

Owner decision: progressive enhancement with one hand-written first-party script. CSP gains
`script-src 'self'; connect-src 'self'` (no inline script, no eval); the script uses no cookies or
storage (state in the URL fragment, never sent to the server), builds DOM with `createElement`
(no `innerHTML`), and only fetches the page's own `cells.json`. Static assets are versioned by the
hash of the manifest and the static files.

## R4. Default state and custom bins

The default must equal the prebuilt preview (constitution VI: the browser does not recompute what
the library made). `cells.json` therefore carries each cell's class *as built* (including the
blend texture and, for rank methods, the supply-capped ranking). Colors-only changes reuse those
classes. Changing the class count or a bound classifies raw cell values with the CLI's `bins` rule
(`searchsorted(..., side="right")` on the inner bounds, i.e. [lower, upper)). For rank methods the
starting bounds are midpoints between the last value of one class and the first of the next in
sorted order (blend swaps cells in pairs, so counts are the ranking's). A new class count resets
bounds to equal-share bounds and samples colors evenly along the current ramp.

## R5. Ice regions without a new dataset

- No ice mask exists on this branch. The unmerged `013-rainfall` branch uses region overrides for
  land ice (Antarctica south of 60° S; Greenland box 59° N+, 75° W–10° W, minus Iceland ≤ 67° N and
  east of 26° W) and an NSIDC sea-ice concentration climatology (60 files, a netCDF-4 reader and a
  new dependency). Bringing NSIDC here would add a dependency and duplicate unmerged work, so it is
  out of scope (brief: no new datasets unless trivial).
- Land ice: the same regions as 013 → 711 land cells.
- Sea ice: tried the ERSST LTM *annual-mean* missing mask first: only 311 cells, mostly the North
  Pole row and coasts, almost no Antarctic sea ice (ERSST fills ice with about −1.8 °C rather than
  leaving it missing). Then the *warmest month* of the 12 long-term monthly means (perennial ice
  keeps the water at freezing even in the warmest month): ≤ −1.5 °C gives 796 cells (691 north,
  105 south), ≤ −1.0 °C gives 930, against 759 for 013's NSIDC rule. Chose −1.5 °C, plus cells with
  no ERSST value poleward of 60°. Added `reduce="monthly-max"` to the netCDF-3 reader.
- Packaged as `kit_31203_ice.json` (cell indices in kit coordinates, `source` block with rules, URL,
  SHA-256, citation, license), regenerated by `python -m kit31203 ice-mask` with `--check` (verified:
  "no differences"). Maps never read it.

## R7. Sizes and speed

`cells.json` 85–141 kB per variant (compact JSON); 18 variants ≈ 2.3 MB. `palette.js` ≈ 20 kB.
A recolor of 10,240 studs took 4 ms in Chromium.
